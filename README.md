# My Football Lab

面向足球爱好者的个人足球训练、比赛记录与战术可视化工具。当前版本为公开内测版。

## 主要功能

- 首页：今日训练、下一场比赛、观赛提醒、历史日历与周期统计
- 训练：快速训练、自定义训练、训练库、组数设置和训练计时；训练计划模块待开发
- 比赛：未来赛程、已结束比赛、照片、备忘录以及与首发阵容的联动
- 战术板：5v5/7v7/8v8/11v11、阵型模板、球员号码与名称、拖拽、路线、区域和关键帧
- 我的：ChatGPT 账号登录、球员档案、主队、关注球队、提醒偏好与足球照片墙

训练动作示意和战术板共用同一套球场元素与坐标思路。

## 账号与数据

公开网站支持使用 ChatGPT 账号登录。登录后，结构化个人数据存入 Cloudflare D1，照片存入 Cloudflare R2；未登录时仍可体验主要页面，修改的数据仅保存在当前设备。

账号身份由站点托管平台提供，项目本身不保存密码。所有数据接口都在服务端校验当前登录用户，个人数据按用户隔离。

## 内测说明

- 首页、历史统计和部分比赛内容包含用于展示产品结构的初始数据。
- 训练计划模块、战术预演保存和系统级观赛通知仍在开发中。
- 观赛提醒当前展示赛程和提醒偏好，但不会发送浏览器、系统或邮件推送。
- 请勿上传无权公开或保存的照片、队徽及其他素材。

## 足球赛事数据

球队名单和下一场比赛通过服务端代理读取 football-data.org，API Token 不会暴露在浏览器代码中。当前覆盖英超、西甲、意甲、德甲和法甲；中超暂时使用内置名单。

本地开发时在 `.dev.vars` 配置：

```text
FOOTBALL_DATA_TOKEN=你的_token
```

密钥文件不会提交到代码仓库。未配置 Token 或数据源暂时不可用时，界面会使用内置球队名单。

## 本地运行

要求 Node.js 22.13 或更高版本。

```bash
npm ci
npm run build
npm start
```

默认地址为 `http://127.0.0.1:4173/`。本地 D1/R2 和 ChatGPT 登录行为由 Sites 开发环境提供。
