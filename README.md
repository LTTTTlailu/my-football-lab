# My Football Lab

面向足球爱好者的个人足球训练、比赛记录与战术可视化原型。

## 当前模块

- 首页：今日训练、比赛与近期记录
- 训练：单人/多人计划、动作库、组数/次数/时间、计时与历史
- 比赛：赛程、个人表现与赛后笔记
- 战术板：5v5/7v7/8v8/11v11、阵型、拖拽、路线、区域与关键帧
- 我的：本地账号原型、可编辑球员档案、主队、提醒偏好与照片墙

训练动作示意和战术板共用同一套球场元素与坐标思路。

## 五大联赛数据

球队名单和下一场比赛通过服务端代理读取 football-data.org，API Token 不会暴露在浏览器代码中。支持：

- 英超 `PL`
- 西甲 `PD`
- 意甲 `SA`
- 德甲 `BL1`
- 法甲 `FL1`

在本地创建 `.dev.vars`：

```text
FOOTBALL_DATA_TOKEN=你的_token
```

未配置 Token 或数据源暂时不可用时，界面会自动使用内置球队名单；中超目前仅使用内置名单。

## 本地运行

要求 Node.js 22.13 或更高版本。

```bash
npm ci
npm run build
npm start
```

默认本地预览地址为 `http://127.0.0.1:4173/`。
