# My Football Lab

面向足球爱好者的个人足球训练、比赛记录与战术可视化工具。当前版本为公开内测版。

## 主要功能

- 首页：今日训练、下一场比赛、关注球队赛程、历史日历与周期统计
- 训练：快速训练、自定义训练、训练库、组数设置和训练计时；训练计划模块待开发
- 比赛：未来赛程、已结束比赛、照片、备忘录以及与首发阵容的联动
- 战术板：5v5/7v7/8v8/11v11、阵型模板、球员号码与名称、拖拽、路线、区域和关键帧
- 我的：本地档案、球员档案、主队、关注球队与足球照片墙

训练动作示意和战术板共用同一套球场元素与坐标思路。

## 账号与数据

本版本不提供云端账号和跨设备同步。球员档案、训练、比赛、阵容、主队和提醒偏好使用浏览器 `localStorage` 保存，照片使用浏览器 `IndexedDB` 保存；这些个人内容不会上传到项目服务器或 GitHub。

用户可以设置一个仅用于首页问候和本地识别的昵称，它不是登录账号，也不包含密码。清除浏览器数据、使用无痕模式、更换浏览器或更换设备后，本地记录可能丢失，请勿把当前版本作为唯一的数据备份。

## 内测说明

- 首页、历史统计和部分比赛内容包含用于展示产品结构的初始数据。
- 训练计划模块、战术预演保存和系统级观赛通知仍在开发中。
- 打开网站时会读取主队及关注球队下一场已公布的比赛；当前不发送浏览器、系统或邮件推送。
- 请勿上传无权公开或保存的照片、队徽及其他素材。

## 足球赛事数据

球队名单和下一场比赛通过服务端代理读取 football-data.org，API Token 不会暴露在浏览器代码中。当前覆盖英超、西甲、意甲、德甲和法甲；中超暂时使用内置名单。

本地开发时在 `.dev.vars` 配置：

```text
FOOTBALL_DATA_TOKEN=你的_token
```

密钥文件不会提交到代码仓库。未配置 Token 或数据源暂时不可用时，界面会使用内置球队名单。

## 本地运行

要求 Node.js 22.13 或更高版本。

```bash
npm ci
npm run build
npm start
```

默认地址为 `http://127.0.0.1:4173/`。个人数据始终保存在访问该地址的浏览器内。

## EdgeOne 发布

项目包含 EdgeOne Pages 适配层。生成可直接上传的发布包：

```bash
npm run build:edgeone
```

生成目录为 `edgeone-dist`。部署时需要在 EdgeOne 项目中配置服务器环境变量
`FOOTBALL_DATA_TOKEN`，个人训练、比赛和照片数据仍只保存在访问者自己的浏览器中。

EdgeOne 的系统项目域名在“全球可用区（含中国大陆）”仅提供限时预览链接；长期公开访问需要绑定已备案的自有域名。

## GitHub Pages 发布

没有自有域名时，可将静态版本发布到 GitHub Pages。先更新公开赛程快照，再生成 `docs` 目录：

```bash
npm run update:football-data
npm run build:pages
```

GitHub Pages 版本从同仓库的静态 JSON 读取球队和下一场比赛，不会在浏览器中暴露 Football-Data.org API Token。个人数据仍只保存在浏览器本地。
